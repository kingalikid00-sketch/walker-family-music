# The Walker Family

**A Lifetime of Music. A Legacy of Memories.**

A premium, mobile-first website for personalised original songs.

## Current build
- Premium dark walnut, cream and gold visual direction.
- Main landing page with the $99 USD offer and four-working-day delivery target.
- Order-form front-end preview.
- Draft privacy and terms pages.

## Launch status
The order form is currently a front-end preview. It does not submit or store orders and does not take payment. Paystack checkout must use server-side transaction initialization and verification before customer payments are accepted. Never put Paystack secret keys in browser code or source files.

## Image asset
The approved family image should be added at `assets/walker-family.jpg` to populate the hero background.

## Deployment
GitHub Pages can host the static website. A secure backend is still required for orders, payment verification, private admin access and delivery emails.
